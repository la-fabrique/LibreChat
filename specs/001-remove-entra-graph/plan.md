# Implementation Plan: Remove Azure Entra ID / Graph API Code

**Branch**: `001-remove-entra-graph` | **Date**: 2026-06-04 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-remove-entra-graph/spec.md`

## Summary

Remove all Azure Entra ID and Microsoft Graph API code from LibreChat as Step 1 of the Keycloak migration. Three service files are deleted outright; ~20 source files are cleaned of Entra-specific code paths. `OboTokenService.js` is preserved (generic OBO, used by MCP). The group schema is simplified from `local|entra` to `local`-only. No existing users or active Entra deployments are affected.
